1. Give the system experience

Choose a repeating visual world. Each intact example updates 36 fragment prototypes and their neighboring feature differences. Tests use fresh examples that weren't taught.

What changed inside?

These 36 locations store averaged *sieve features*: color core, a 3×3 luminance map, orientation and contrast. Neighboring locations also learn their expected feature differences. They are fixed spatial links, not automatically discovered object parts.

What this demonstration does — and what it doesn't

This is an interpretable assembly model. It learns from complete images without labels. A globally optimized one-to-one assignment and local swap search find plausible tile positions. The animated tile swaps show the resulting computed arrangement; they are not simulated neural firing. For evaluation only, the app retains original tile indices and measures exact placement and pixel error; the optimizer never reads them.

Its learned locations assume a stable visual layout. The built-in worlds are stylized and deliberately structured. For your own photos, teach multiple similar compositions, then test a different photograph. Diverse unrelated photographs, changing camera angles, repeated blank sky, and unfamiliar subjects can defeat this model. It does not yet invent details, discover movable object groupings, implement dendrites, or qualify as a competitive modern generative model.

Next research step: hierarchical coarse-to-fine groups with learned conditional predictions, explicit missing-patch synthesis, held-out real photographs, and controlled comparisons against seam-only jigsaws and ordinary image priors.
